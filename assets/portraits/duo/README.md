# Duo-Gegner – Arcane Duel

Dieser Uploadordner ist bereit. **duo-chapter-01-a.webp bis duo-chapter-15-b.webp. A = erster Gegner (Sitz 1), B = zweiter Gegner (Sitz 3).**

Bilder quadratisch (empfohlen 512 × 512 Pixel) als `.webp` oder `.png` mit der genauen Portrait-ID benennen. Dateien nach `development` hochladen und die Seite neu laden. Fehlende Bilder haben automatisch ein Platzhalterportrait.

Die vollständige Liste steht unter [Portrait-Manifest](../../portrait-manifest-v215.json).
